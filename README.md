# Анализ социальных сетей и графы взаимодействий

Проект для студенческого научного семинара
«Обработка Естественных Языков»: анализ социальных сетей, графы подписок, репостов и упоминаний,
меры центральности и каскады распространения информации. 

## Состав

| Путь | Что делает |
| --- | --- |
| `sgl/graph.py` | ориентированный взвешенный граф на разреженных матрицах |
| `sgl/higgs.py` | загрузка набора Higgs (SNAP), слои на общем множестве вершин, проверка направления |
| `sgl/extract.py` | этап 2: связи из текста (`RT @имя:`, `@имя`, ответ), точность и полнота |
| `sgl/measures.py` | восемь мер: степени, близость, посредничество (Брандес), собственный вектор, PageRank, HITS, k-ядра |
| `sgl/cascade.py` | модели IC, WC, LT; общие случайные числа; точное σ(S) перебором для проверки |
| `sgl/service.py` | логика веб-сервиса (кэш в памяти, без базы данных) |
| `app/` | FastAPI и страница на чистом JavaScript (без внешних библиотек и без CDN) |
| `scripts/compute_metrics.py` | таблица «вершина × мера» для слоя Higgs, проверка направления рёбер |
| `scripts/run_experiments.py` | эксперименты 1–4 из части III (на учебной сети или на слоях Higgs) |
| `results_synthetic.json` | результаты экспериментов на учебной сети (1500 вершин) |
| `tests/` | 43 теста: значения G1 и G2 из теории, сверка с NetworkX, свойства каскадов |

## Запуск в Docker

```
docker build -t graph-lab .
docker run --rm -p 8000:8000 -v "$PWD/data:/data" graph-lab
```

Откройте http://localhost:8000. 

## Запуск без Docker

```
pip install -r requirements.txt
SGL_DATA_DIR=./data uvicorn app.main:app --port 8000
```
